# Индивидуальный проект «Объясни задачу: Чтение и анализ блок-схем»

Обучающее интерактивное веб-приложение для освоения темы **«Чтение, анализ и трассировка блок-схем алгоритмов ветвления»**, разработанное на строго типизированном языке **C#** с использованием веб-технологии **Blazor WebAssembly** (.NET 9).

---

## 🚀 Быстрый запуск

### Требования к окружению
- **.NET SDK 8.0** или **9.0** ([скачать с официального сайта Microsoft](https://dotnet.microsoft.com/download))
- Любой современный веб-браузер (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari)

### Запуск проекта локально
1. Клонируйте или откройте каталог проекта в терминале:
   ```bash
   cd FlowchartExplainer
   ```
2. Запустите приложение командой:
   ```bash
   dotnet run
   ```
3. Откройте адрес в браузере (обычно `http://localhost:5000` или `https://localhost:5001`).

### Запуск автоматических тестов
Все 5 обязательных проверочных сценариев автоматизированы в проекте `FlowchartExplainer.Tests`:
```bash
dotnet test
```

## 📚 Содержание и обязательный объём проекта

Приложение полностью покрывает обязательный объём и рассматривает все типы задач темы:

### 1. Три блок-схемы (ГОСТ 19.701-90 / ISO 5807)
1. **Вводная схема:** *«Чётность суммы двух чисел»*
   - 1 условие (`sum mod 2 == 0`), операция сложения `sum = a + b`.
   - Ветвление на «Да» (чётное) и «Нет» (нечётное).
   - Вопросы самопроверки: вычисление суммы и определение ветви по остатку.
2. **★ Основная схема:** *«Расчёт покупки со скидкой и тип доставки»*
   - 2 последовательных условия:
     1. `total > 1000 ?` — расчёт скидки 20% или 5%.
     2. `final_sum >= 1200 ?` — присвоение статуса «VIP (Бесплатно)» или «Стандартная доставка».
   - 3 интерактивных вопроса пользователю внутри шагов алгоритма (вычисление произведения `price * qty`, выбор ветви скидки и расчёт итоговой суммы).
3. **Особый случай / типичная ошибка:** *«Деление с защитой от деления на 0»*
   - Защитное условие (Guard Clause): `b == 0 ?`.
   - При `b == 0` — безопасный аварийный выход без сбоя программы с выводом предупреждения.
   - При `b != 0` — вычисление целой части `q = ⌊a / b⌋` и остатка `r = a mod b`, проверка условия делимости нацело (`r == 0 ?`).

### 2. Типы задач
- **Тип 1:** *Определение результата выполнения готовой схемы по исходным данным.*
  - Пользователь задаёт входные параметры через слайдеры/числовые поля или использует готовые пресеты («Скидка 20% + VIP», «Скидка 5% + Стандартная», «Деление на 0»).
  - Пошаговый разбор с кнопками «Вперёд», «Назад», «Сначала» и автоматическим проигрыванием с паузой.
  - Таблица переменных в реальном времени с фиксацией старого и нового значений (`1200 руб. (было 0)`) и подробной подстановкой формулы (`total = 120 * 10 = 1200`).
- **Тип 2:** *Подбор входных данных в заданном диапазоне для получения заданной ветви.*
  - Раздел «Самостоятельная задача»: подобрать такие цену (`price` 50..250 руб.) и количество (`qty` 5..20 шт.), чтобы заказ получил скидку 20% (`total > 1000`), но доставка осталась «Стандартной» (`final_sum < 1200`).
  - Интеллектуальный анализатор ошибок: объясняет, какое именно условие нарушено, даёт подсказку с математическим обоснованием и позволяет повторить попытку.

## 🏛️ Архитектура и стек технологий

| Компонент | Назначение |
| :--- | :--- |
| **Язык** | **C# 12** (строгая статическая типизация, `record`, `readonly struct`, `nullable reference types`) |
| **Веб-платформа** | **ASP.NET Core Blazor WebAssembly (.NET 9)** — 100% C# на клиенте |
| **Визуализация** | Векторный интерактивный **SVG** (овалы, параллелограммы, прямоугольники, ромбы, метки «Да»/«Нет», подсветка активного узла пульсацией) |
| **Тестирование** | **xUnit** — автоматизированная верификация расчётов и ветвлений |

Подробное описание архитектуры, движения данных и размещения частей в коде представлено в файле [**`ARCHITECTURE.md`**](ARCHITECTURE.md), а также во встроенном модальном окне приложения **«🏛️ Архитектура и защита»**.
